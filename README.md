# 모두의 계산기 (Modoo Calc)

한국어 사용자에게 일상 계산 도구를 제공하는 정적 웹사이트의 시작 프로젝트입니다.

## 현재 포함된 기능

- 할인 가격 계산기
- 계산 방법과 주의사항
- 사이트 안내 및 개인정보처리방침 초안
- Node.js 내장 테스트
- GitHub Actions 자동 테스트와 Astro 빌드
- 광고 코드 기본 비활성화 및 빌드 산출물 검사

## 실행 방법

Node.js 22 이상을 설치한 뒤 프로젝트 폴더에서 실행합니다.

```sh
npm install
npm test
npm run dev
```

정적 빌드:

```sh
npm run build
npm run preview
```

## 배포

Cloudflare Pages와 GitHub 저장소를 연결했다면 빌드 명령은 `npm run build`, 빌드 출력 디렉터리는 `dist`로 설정합니다. 실제 배포 설정은 대시보드에서 확인해야 합니다.

## 정책 및 운영 메모

- 광고는 기본적으로 포함하지 않습니다.
- 개인정보처리방침은 현재 기능에 대한 초안이며, 광고·분석·쿠키 등을 추가하기 전에 실제 운영 방식에 맞게 검토해야 합니다.
- 계산기 결과가 실제 거래 조건과 다를 수 있으므로, 추가 계산 도구는 각각의 공식과 경계값을 테스트한 뒤 공개합니다.
- 테스트와 빌드는 CI에서 실행되도록 설정되어 있습니다. CI 통과와 실제 Cloudflare 배포 성공은 별개로 확인해야 합니다.
